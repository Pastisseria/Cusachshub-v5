# Cusachs Hub v3

ERP base para Pastisseria Cusachs, construido con React, Vite y Supabase.

## Instalación

1. Abre esta carpeta con Visual Studio Code.
2. Abre **Terminal > Nueva terminal**.
3. Ejecuta `npm install`.
4. Copia `.env.example` y renómbralo a `.env`.
5. Añade la URL y la clave pública de Supabase.
6. Ejecuta `npm run dev`.
7. Abre la dirección que aparece en la terminal, normalmente `http://localhost:5173`.

La aplicación puede abrirse sin Supabase en **modo demostración**. Los datos quedarán temporalmente en el navegador.

## Módulos incluidos

Dashboard, clientes, productos, presupuestos, catering, producción, dietario anual, menaje, bebidas, ingredientes, escandallos, proveedores, catálogo de proveedores, comparador, compras, visitadores médicos, fichas técnicas, facturación y motor de documentos.
